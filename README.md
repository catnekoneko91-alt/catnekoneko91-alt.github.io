# ポートフォリオ公開サイト

HTML,CSS,JavaScriptを用いて作成するポートフォリオサイト
Webサイトの制作、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発が目的

## 公開サイト

**URL:**[NekoF91](https://catnekoneko91-alt.github.io/)

GitHub Pagesを利用して公開

## 使用技術・開発環境
- フロントエンド …HTML5,CSS3,JavaScript
- 開発環境 …EclipseIDE
- バージョン管理 …Git/GitHub
- 開発フロー …GitHub Flow
- ホスティング …GitHub Pages

## 開発・バージョン管理
開発にはGitHub Flowを採用

バージョン番号は[Semantic Versioning](https://semver.org/lang/ja/)を参考に管理し、
リリース時にはＧｉｔタグとGitHub Releasesを利用

## 変更履歴・リリース情報
各バージョンの変更履歴は、Keep a Changelogを参考に'CHANGELOG.md'で管理

- **[CHANGELOG.md](CHANGELOG.md)** － バージョンごとの変更内容
- **[GitHub Releases](https://github.com/catnekoneko91-alt/catnekoneko91-alt.github.io/releases)**
― リリースノート・Ｇｉｔタグ・ソースコード
